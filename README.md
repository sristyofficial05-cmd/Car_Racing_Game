# 🏎️ Car Racing Game - Python (Pygame)

A fun and interactive 2D car racing game built using Python and Pygame.  
The player controls a car, avoids obstacles, and scores points as the speed increases.

---

## 🎮 Features

- 🚗 Player-controlled car movement (left/right)
- 🛣️ Infinite scrolling road
- 🚙 Enemy cars with random movement
- 💥 Collision detection & crash animation
- 🔊 Sound effects (crash, movement)
- 🧮 Score & High Score system
- ❤️ Lives system
- ⚡ Power-ups (speed boost, extra life)
- 🎯 Increasing difficulty levels
- 🔁 Restart & Quit options
- 🎨 Smooth animations & UI

---

## 🛠️ Tech Stack

- Python 3
- Pygame Library
